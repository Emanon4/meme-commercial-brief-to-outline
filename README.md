# Meme｜商单前策工作台 / Commercial Brief to Outline

这是 Meme 项目「多工序撰稿设计环节链」中的独立 Codex Skill，用于「分析 Brief—创意脑暴—大纲制作」。客户 Brief 始终是最高约束；创意不会凭空随机生成，而是从群众基础、情绪浓度、认知反差、社交货币、话题张力和价值获得逐项发散，再把有潜力的方向交叉组合。你选择、组合或修正创意以后，它才制作结构大纲。

## 它与直接让 AI 给十几个点子的区别

普通提示词往往先生成一批形式点子，再用「有共鸣」「有反差」解释它们。这个 Skill 强制保留相反的顺序：先从每个选题调研维度提出问题，每个适用维度产生多个短思路，再组合成六到十个完整方向。没有真实依据的群众情绪、争议和传播行为必须写成待调研假设。

适配与风控负责删除违反 Brief、虚构事实、制造伪争议或不符合账号与平台的方向。模型会推荐更有曝光潜力的候选，但不使用总分替代人的审美判断。

## 工作流

```text
客户 Brief：最高约束
→ 精准解读要求与可发挥空间
→ 按选题调研维度分别发散
→ 交叉组合为完整创意方向
→ 人选择、组合或否决
→ 形成结构大纲
→ 人确认后生成数字人导演交接包
```

`Bxx` 记录客户要求，`Cxx` 记录完整创意方向，`Oxx` 记录大纲段落，`Dxx` 记录人的选择与理由。创意可以在 Brief 解读尚待修正时作为探索出现，但不得跳过人的选择直接生成大纲。

## 校验

```bash

```

校验器检查 Brief 映射、选题调研维度覆盖、人工闸门和交接状态，不评价创意审美。

## 隐私边界

仓库只包含空模板、方法说明和虚构品牌测试案例。真实客户 Brief、联系人、预算和未发布创意应保存在本地忽略目录或权限受控文档中，不得提交到公开仓库。
